#Imperium Engine

A free open-source 3D game engine, writen in C# .NET 10, designed for making 6-th gen & A-AA video games quickly.



### Syntax

#### Comment Regions
Comment regions are used to specify a region of code to make it easier to read. An example might be:
```
// ----------------------------------------------------
// Physics
// ----------------------------------------------------
```
Region types:

| symbol | use                                                                     |
|--------|-------------------------------------------------------------------------|
| `#`    | between mutliple type (class/struct/etc.) declarations in a single file |
| `+`    | seperate STATIC from CLASS                                              |
| `=`    | between type declarations (ver, actions, func, etc.)                    |
| `-`    | inside a function                                                       |
